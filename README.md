# AI Hub — Modern AI Directory Website

![AI Hub Banner](https://raw.githubusercontent.com/username/repo/main/banner.png) <!-- Note: Replace with actual banner if available -->

**AI Hub** is a premium, high-performance static directory designed to showcase the world's most powerful AI chatbots. It provides a curated gateway for users to discover, compare, and launch leading AI assistants from a single, beautifully crafted interface.

---

## ✨ Key Features

- **🚀 15+ Curated AI Bots**: Includes industry giants like ChatGPT, Gemini, and Claude, alongside emerging powerhouses like DeepSeek, Kimi, and Qwen.
- **🔍 Intelligent Search**: Instant search functionality that filters by name, company, description, or specific feature tags.
- **🏷️ Category Filtering**: Quickly narrow down your search using pre-defined categories such as *Reasoning*, *Research*, *Productivity*, and *Aggregators*.
- **💎 Premium Aesthetics**: 
    - **Glassmorphism**: Elegant translucent UI components with blurred backgrounds.
    - **Dark Mode**: A sleek, eye-friendly design optimized for modern displays.
    - **Dynamic Background**: An interactive canvas-based particle system and floating ambient orbs.
- **📱 Fully Responsive**: Seamless experience across mobile, tablet, and desktop devices.
- **⚡ Performance Optimized**: Minimalistic tech stack (Vanilla JS/CSS) ensuring lightning-fast load times.
- **⌨️ Power-User Features**: 
    - Press `/` to focus the search bar instantly.
    - Press `Esc` to clear search and blur input.
    - Smooth scroll-to-top navigation.

## 🎨 Design Philosophy

The project was built with a "Visual First" approach, focusing on three main pillars:
1.  **Depth & Layering**: Using noise overlays, glassmorphism, and radial gradients to create a sense of three-dimensional space.
2.  **Micro-Animations**: Subtle hover effects, staggering card entries, and pulse animations to make the UI feel alive.
3.  **Information Density**: Balancing a rich visual style with clear, readable descriptions and high-contrast typography.

## 🚀 Getting Started

Since this is a static website, no complex installation or backend is required.

1.  **Clone the Repository**:
